# Dragon Tower

모바일 세로 화면을 기준으로 제작 중인 Unity Web 로그라이크 게임입니다.

## 개발 환경

- Unity `6000.3.10f1`
- Built-in Render Pipeline
- 세로 화면 `480 × 850` 기준

Unity Hub에서 이 저장소 폴더를 프로젝트로 추가한 뒤 열면 됩니다.

## 게임 흐름

랜덤 알 부화 → 드래곤 수집 및 선택 → 타워 방 선택 → 전투와 성장 → 5레벨마다 증강 선택 → 10층마다 보스 전투로 진행됩니다.

## Git에 포함하지 않는 파일

Unity가 자동 생성하는 `Library`, `Temp`, `Logs`, `UserSettings`, 빌드 결과물은 저장소에서 제외합니다.

`Assets/Eric VFX Studio`는 외부 Asset Store 패키지이므로 저장소에 포함하지 않습니다. 패키지 소유자는 Unity에서 자신의 라이선스 사본을 다시 가져오면 기존 스킬 데이터의 프리팹 GUID 연결이 복구됩니다. 패키지가 없어도 게임은 기본 2D 전투 이펙트로 실행됩니다.

## 콘텐츠 편집

Unity 메뉴에서 `Dragon Tower → 콘텐츠 관리`를 열면 드래곤, 몬스터, 스킬, 아이템과 증강을 편집하거나 CSV로 내보낼 수 있습니다.
