단천(斷天) 구현 결과
적용 위치: C:\Users\PC\Dragon_Tower

구현
• 제피르 전용 Legendary Skill Data / 독립 VFX / 전용 대각선 절단 아이콘.
• 암전과 제피르 강조 → 바람 압축 → 전장을 관통하는 대각선 절단 → 짧은 정적 → 실제 피해와 균열 폭발 → 에너지 분출/20개 파편 → 복구.
• 기존 캐릭터 Skill 프레임 사용. HUD 구조/기존 네 스킬 에셋과 VFX는 변경하지 않음.
• 배경에만 작은 UV 이동을 적용해 화면이 벌어지는 착시. 실제 Camera, 전역 Time.timeScale, 오디오 설정은 변경하지 않음.
• 명중 시 기존 silhouette shader 기반 밝은 피격 Flash, 짧은 시각적 정지, 방향성 Recoil. 큰 피해 숫자는 기존 숫자 풀/폰트를 사용.

무적
• 성공적으로 발동한 순간부터 연출 종료(기본 1.3초)까지 무적.
• 일반/보스 공격, 이미 걸린 화상/찰과상, 반사, 방벽 폭발 차단.
• 연출 중 봉인/기절 방해와 자동 회피/연속 입력으로 시전이 중단되지 않도록 보호.
• 추가 공격/회피/스킬 입력은 연출 동안 거절. 쿨타임 초기화로도 중첩 시전 불가.
• 회피 성공으로 처리하지 않으므로 회피 관련 추가 보상은 발생하지 않음.
• 기존 지속 상태를 지우지 않고 보호 시간 중 피해만 무시. 종료 후 정상적으로 피해 재개.
• 전투 종료, 교체, 스킬 컴포넌트/Overlay 비활성화 시 무적·예약 피해·화면 상태 정리.
• 원래 스킬 실패 조건(기존 마비에 의한 발동 실패 등)에서 무적만 얻는 문제 방지.
• 기존 스킬 사용 HP 비용 등 의도된 비용은 기존 규칙 유지.

증강 보상 생성 때 0.5% 확률로 후보 풀에 진입한 뒤 기존 선택 추첨을 거칩니다.
따라서 실제 최종 등장 확률은 0.5%보다 낮습니다. 수치는 Inspector에서 조정 가능.
연출은 Protected Cast Duration과 실제 전투 시계를 기준으로 복구하며, 실제 피해 Cue가 와야 폭발/명중 피드백을 표시합니다.

검증
Unity 실제 전투 버튼 경로에서 3회 반복 사용.
피해 1회와 약 0.45초 타이밍, 무적 경계, 종료 후 피격 재개, 쿨타임 확인.
지속 피해/반사/방벽 폭발/타이밍 봉인/마비 실패/쿨타임 초기화 중 재입력 검증.
폭발 전/폭발 도중 컴포넌트 중단, Overlay 비활성화, 전투 종료, 다른 전투 진입 8개 시나리오 복구 확인.
타깃 사망 시 즉시 화면 정리. Time.timeScale/HUD 위치 보존 및 오브젝트 수 증가 없음.
기존 질풍강타/바람칼날/질풍참/귀참/입력/Theme/전투 기능 검증 통과.
기존 보호 대상 파일 해시 동일. 기존 네 스킬 VFX/데이터/HUD/배경 미수정.

성능 구조
256×128 전용 픽셀 시트, Point 필터, mipmap 없음.
38개 Image 고정 풀. 압축 파편 16개 / 잔류 파편 20개를 같은 슬롯으로 재사용.
기존 WindSkillRecipe, GaleSlashImpact, GaleSlashShockwave, silhouette shader 재사용.
배경 1회 텍스처 샘플의 단순 UV 이동. 새 RenderTexture/실시간 조명/Blur/매 시전 Instantiate 없음.
실제 모바일 기기의 GPU 프레임 시간/드로우콜은 미측정.
