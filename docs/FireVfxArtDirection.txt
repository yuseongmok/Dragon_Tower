Palette (cold exterior -> hot interior)
Deep Crimson #3E0D1B; Crimson #971925; Red Orange #E03518;
Orange #FF7119; Golden Yellow #FFBE36; Pale Yellow #FFE79A;
White-hot #FFFDE2. Smoke #35232A with warm brown/crimson folds.
FireStyle.asset is the shared style configuration. Setup regenerates the atlas
from its palette; palette edits require regeneration for baked sprite colors.

Living Flame
Distinct dark silhouette, orange body, gold interior, white core, secondary tongue.
Their animated shapes, proportions, phase, sway and speed differ; not recolored copies.
Sharp curved tips, asymmetrical lobes, white lower core and rising embers.
14fps sprite frames with continuous layer motion. Point filtering; no mipmaps.

Explosion
Compressed ignition -> short white-hot flash -> expanding irregular orange mass
and crimson exterior -> outward-curving flame tongues -> flying embers -> rear smoke
-> small flames, ground heat and residual embers. Different expansion rates.
Nearby embers grow and brighten; rear embers remain smaller/darker.
Heat is a faint animated broken pixel layer, not a screen distortion pass.
Smoke is short-lived irregular pixel geometry behind the main fire and enemy.

Burn status
Reads existing BattleModel.EnemyBurning. Small side flames, 8 rising embers,
weak ground glow. Face/torso remain readable. Clears with status, death or exit.
The review driver invokes the existing ApplyBurn method for a 3-second sample;
this is test-only and does not create a new Burn system. Existing tick behavior intact.

Rendering / reuse
One 768x960 RGBA atlas, 80 frames (10 modules x 8 frames), CPU copy disabled.
DarkFlame / Body / Inner / Core / Burst / Smoke / Heat / Ember / Shockwave / Tongue.
Alpha body/smoke: Unity UI/Default.
Highlight: FireHighlight.mat reuses generic DragonTower/Wind Claw Highlight shader
(SrcAlpha One additive, UI clip support); no Wind art or timing borrowed.
Four pooled rear/front alpha/additive groups; 384 reserved Images, measured peak 138.
No per-frame Instantiate/Destroy, no new realtime lights/bloom/fullscreen pass.
Prototype clip region protects top/bottom HUD; all images ignore pointer raycasts.
Pool size is current capacity, not a rule limiting future Fire art quality.
