Ice VFX Depth Batch — 2026-10-02

대상: 아이스샷, 서리숨결, 아이시클의 시각 연출만 개선.
아이스볼은 승인된 모습 그대로 유지. Legendary 제작 없음.

아이스샷
- 8프레임 결정면 반사광을 가진 고드름, 짧은 잔상 두 겹, 밝은 선두 하이라이트.
- 서로 다른 출발점과 곡선 경로를 통해 같은 적에게 수렴하는 3연사.
- 실제 각 타격 이벤트에서 파쇄 Impact. 3타는 더 큰 중심광과 파편.

서리숨결
- 캐릭터 Skill Origin부터 적까지 넓어지는 흐름. 8프레임 난류 단면과 움직이는 냉기 덩어리.
- 앞뒤로 회전하며 이동하는 소수의 결정 파편, 밝기가 다른 내부 레이어.
- 실제 5 Hit에 맞춘 짧은 접촉 맥동, 마지막 Hit에서 더 큰 파쇄.

아이시클
- 기존 지면 균열과 3 Hit 시간 유지. 고정된 바닥에서 5개의 결정이 성장.
- 적 뒤의 어두운 결정과 앞의 밝은 결정을 분리. 결정면 반사광 변화.
- 마지막 실제 타격에 중심 Impact, 이어서 결정 파쇄, 원근 크기 변화가 있는 큰 파편, 타원 충격파.

재사용
- 기존 64 Image 풀, 전투 안전 영역 마스크, 적 앞/뒤 레이어.
- 아이스볼의 폭발/충격파/중심광 프레임과 Highlight Material.
- 기존 Ice Style 팔레트, Shard/Frost/Crack 모듈.
- 신규 Material/Shader 없음. 새 아틀라스 768x288 / 24프레임 / Point / no mipmap / PPU 100.
