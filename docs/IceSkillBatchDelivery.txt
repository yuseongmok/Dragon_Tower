1. 아이스샷 / Common
단단한 고드름 3개를 0.11초 간격으로 발사. 첫 명중 0.20초.
Dark Face / Ice Body / Cyan Edge / White Ridge, 작은 Frost 꼬리.
실제 Hit마다 4개 이하 작은 파편과 짧은 균열. 과한 발광 없음.

2. 아이스볼 / Rare
약 0.10초 동안 현재 Casting Origin에서 작은 구체가 응축된 뒤 발사.
구체 내부의 회전 결정과 반사광, 첫 직접 충돌 후 표면 균열.
0.24초 뒤 두 번째 Hit에서 냉기 확장·결정 생성·10개 파편.
고드름과 다른 둥근 실루엣.

3. 서리숨결 / Rare
매 프레임 기존 Skill Origin을 읽는 6개 작은 냉기 구간과 소수의 Frost/Ice Dust.
0.16초 간격 5 Hit. 마지막 Impact만 조금 강화.
기존 Skill 키포즈를 표시하는 시간을 연출 중 유지하고 종료 후 기존 Idle로 복귀.
Animation 에셋/State/API는 그대로다. 루나 Staff의 기존 프레임별 Optional Anchor 사용.

4. 아이시클 / Unique
Ground Position에서 적 발밑까지 빠르게 진행하는 균열과 Frost.
형태가 다른 3개 결정(기울어진 가시 / 갈라진 결정 / 여러 면의 군집)이 차례로 성장.
0.18초 간격 3 Hit. 마지막에 White Refraction, 전체 Crack, 12개 큰 구조 파편과 작은 Impact 파편.
마지막 효과만 약 50ms 같은 시각을 유지한다. Time.timeScale, 피해 타이머, 쿨타임은 멈추지 않는다.
HUD 흔들림, 암전, Fullscreen 연출, 새로운 카메라 효과 없음.

5. Damage / Slow
BattleModel의 기존 hitCount/initialHitDelay/hitInterval 예약과 실제 Skill/SkillHit Cue 사용.
해당 Cue에서 Impact를 즉시 표시. 피해 숫자는 33ms 뒤 서로 다른 위치에서 위로 이동.
새 선택 값 statusOnHit=true인 Ice 스킬만 명중 시 Slow 적용/갱신. 다른 스킬 기본값 false로 기존 시전 시 적용 유지.
statusChancePercent=100, statusPower=20/60/30/60.
지속시간은 기존 값 또는 기본 3초: 아이스샷3 / 아이스볼3 / 서리숨결4 / 아이시클4초.
기존 Slow 공식: 공격 간격 × (1 + power/100). 예: 60은 간격 1.6배이며 공격속도 자체 60% 감소 공식은 아니다. 기존 밸런스를 바꾸지 않았다.
기존 더 강한 패시브/아이템 Slow가 있으면 기존 max 규칙이 우선한다. 강도 합산/Stack은 없다.
EnemySlowed, EnemySlowPower, EnemySlowRemaining을 읽어 이후 시스템에 연결 가능.
피해 Cue 출처를 구분해 독·운석 등의 추가 피해가 Ice 스킬 Impact 횟수로 잘못 계산되지 않도록 했다.
데미지 계산식은 그대로다. 현재 1 Hit 피해 / 쿨타임은 52/5.5s, 18/5.5s, 32/7s, 15/10s로 기존 값을 유지한다. 최종 등급 밸런스가 아니다.
